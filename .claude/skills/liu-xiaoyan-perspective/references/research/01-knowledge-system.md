## 一、长难句体系

### 简单句五大句型
1. 主 + 谓
2. 主 + 谓 + 宾
3. 主 + 谓 + 表（系表）
4. 主 + 谓 + 双宾
5. 主 + 谓 + 宾 + 宾补

### 句子成分
| 成分 | 可以由什么充当 |
|------|--------------|
| 主语 | 名词、代词、非谓语动词、从句 |
| 谓语 | 实义动词、系动词 |
| 宾语 | 名词、代词、非谓语动词、从句 |
| 表语 | 名词、代词、形容词、非谓语动词、介词短语、从句 |
| 定语 | 名词、形容词、非谓语动词、从句、介词短语 |
| 状语 | 副词、介词短语、非谓语动词、从句 |
| 同位语 | 名词、代词、非谓语动词、从句 |

### 核心规则
- 表语修饰主语；定语修饰名词
- 介词短语只能作定语、表语、状语（不能作主语/宾语）
- 系动词无被动语态
- 从句和非谓语动词可充当的成分一致

### 长难句公式
```
（状语 / As非限制定语），主语（定语/同位语/状语）+ 谓语 + 宾语（定语/同位语/状语）
```

## 二、阅读理解方法

### 核心规律
- **原句重现 = 必错**：选项原封不动复制原文措辞，100%是干扰项；正确答案必有同义替换
- **按序出题**：四篇文章顺序与题目顺序一致，定位不会跨越
- **长难句是出题点**：每篇必有5-6个长难句，出题老师专在这里设陷阱

### 定位词选取原则
优先选：
1. 首字母大写的人名、地名、机构名
2. 具体时间、年份
3. 阿拉伯数字
4. 专业名词、形容词
（避免选：代词、副词、泛化名词）

### 题型策略
- **态度题**：先排除不可能的态度词（too extreme），再用题干定位段落，看作者论述立场
- **细节题**：严格定位，答案在原文附近，同义替换验证
- **主旨题**：看首段和各段首句，避免过于细节的选项

## 三、写作方法

### 三大写作原则
1. 写不来的词汇 → 换成自己会的词（保证正确）
2. 写不来的长难句 → 写简单句（保证正确）
3. 背一个大作文模板 + 一个小作文模板

### 大作文三段式框架
**第一段（3-4句）：描述图表 + 引出中心**
- "What is obvious is that..."
- 主语从句 + 中心论点

**第二段（4句）：分析原因**
- 总述 + 三点原因（First/Moreover/Last but not least）
- 搭配虚拟语气或让步从句提升档次

**第三段（4句）：总结 + 措施 + 口号**
- 总结问题
- 两点措施
- 升华结尾

### 高分句型
```
被动句：... is supposed to be respected by ...
There be：There remain immense amounts of factors which can account for...
比较：... proves as momentous as ..., which plays a key role in ...
递进：The harder one works, the luckier he will be.
同位语：Teamwork, a Chinese conventional virtue, plays a crucial role...
```

### 高级替换词
| 普通词 | 替换词 |
|--------|--------|
| think | maintain / assert / contend |
| many | a sea of / immense amounts of |
| people | youngsters / the elderly / private individuals |
| good | beneficial / constructive |
| bad | detrimental / adverse |

### 逻辑关系词（只要上下句有逻辑关系，必须用）
- 递进：moreover, furthermore, in addition
- 转折：nevertheless, however, on the contrary
- 因果：consequently, as a result, thereby

### 小作文（书信类）
- 公务书信：称呼 + 自我介绍 + 写作目的 + 正文三点 + 期待回信 + 落款
- 告示Notice：标题 + 正文 + 欢迎语 + 联系方式

## 四、全年备考三阶段规划（《你还在背"单"词吗》前言）

### 第一阶段（3月初—6月底）：基础阶段
- 任务：搞定单词和语法
- 单词学法三步走：
  1. **翻阅**：拿到大纲词汇书翻阅，有印象即可，不强求记住
  2. **精读真题**：只看阅读和翻译文章（不做题），不认识的单词在真题上直接标注（不抄小本）
  3. **背**：早上背晚上背，狂背真题中查出的单词和句子，**要张嘴，不能心念**，每个词最终要看7遍左右

### 第二阶段（7月—11月）：总结+操练
- 需要2002年至今的真题
- 翻译、完型、阅读**四步走**：
  1. 把握时间先把题目做一遍
  2. 核实对错，明确每道题做错的原因
  3. 精读全文
  4. 背（同第一阶段）

### 第三阶段（12月—考前）：总攻
- 复习以前看过的真题、单词、句子、题目
- 考前半月做2-3套模拟题（只为坐在考场上的感觉）
- 考完不要立即对答案

## 五、"不择手段记单词"方法论（书中实例）

### 谐音法
- **ancient**（古代）→ 谐音"俺的神（啊）"，神住在哪个年代？→古代
- **awe**（敬畏）→ 谐音"哦"，导游讲大事件，你只能发出"哦"，因为太敬畏了
- **awful**（可怕的/随意的）→ 谐音"啊比戳蕊"，用飞镖扎花蕊比赛，这个比法是不是很"随意"
- **passive**（消极的）→ 发音似"拍死我"，动不动说"拍死我"，活得太消极了→消极的

### 词根词缀法
- **ascend**（升高）→ as(一再地) + ce(走)→ 一再地朝上走→升高
- **access**（接近）→ ac(一再地) + ce(走)→ 一再地走→接近、靠近
- **absent**（缺席）→ ab(否定) + sent(送)→ 不送→我今天不送女儿上学，她就缺席了
- **attach**（附着）→ at(一再地) + tach(触摸)→ 一再触摸→附着、粘着
- **accelerate**（加速）→ ac(一再地) + cele(赛了)→ 一再地赛了，比赛需要→加速
- **absolute**（完全的）→ ab(一再地) + so(如此) + lute(像late晚)→ 完全的晚了
- **assign**（委派）→ sign(签字)→ 老板签一次字就是委派一个任务

### 故事/场景法
- **astonish**（使惊讶）→ a(一个)石头(stone)你死(nish≈你死)→ 石头差点砸到你→使惊讶
- **agenda**（议程）→ a(一) + gen(件) + da(大)→ 一件大事，放在日程表上→议程
- **accompany**（陪伴）→ company有"朋友"义→ ac一再地做你的朋友→陪伴
- **ally**（同盟国）→ all(所有的)都放在那(ly≈lay放置)→ 韩美军演武器都放在那→同盟国
- **agent**（代理商）→ a(一个)哥哥(g)进来了(ent=enter)→ 代理商

### 形近词辨析（一组一组记）
- rise（上升）/ arise（出现）/ raise（举起）/ rouse = arouse（唤醒）→ 后羿射日故事串联

### 刘晓艳关于查词的建议
- **不用手机查，不用《牛津大辞典》**
- 只查考研大纲词汇书或考研单词书
- 超纲词汇不用掌握，大纲词汇中查不到→直接跳过

### 英汉句法对比框架（书中核心类比）

**英语 = 葡萄串结构（形合）**
> 主干可能很短，累累果实附着在上面。英语重"结构美"，每句必须有主谓，用虚词、从句、非谓语动词来连接。

**汉语 = 竹节结构（意合）**
> 像竹竿一节一节连下去，不靠语法靠逻辑。可以没有主语、宾语，甚至谓语；顺序也可以颠倒。

**实例（奥巴马演讲）：**
> "If there is anyone out there who still doubts...who still wonders...who still questions...tonight is your answer."
> 这是三个 who 引导的定语从句，"果实累累"挂在主干上。汉语翻译反而是简单句，简洁工整。

**英汉三大差异：**
| | 汉语 | 英语 |
|--|------|------|
| 主谓 | 可以没有 | 必须具备 |
| 语序 | 可以乱放 | 必须主谓宾顺序 |
| 语法 | 可以没有 | 每句必须有 |

### 谓语判定三要素（"晓艳有话说"级别重点）
1. **必须是系动词或实义动词** — 情态动词(must/can/will)不能单独作谓语
2. **必须有时态** — "My old flame love me" 错误，因为 love 没有体现时态
3. **必须有语态** — 主语不能发出动作时，用被动语态

**口诀**：谓语 = 具有时态和语态的实义动词（词组）或系动词

### 非谓语三变形法（动词不能单独作其他成分，必须变形）
```
动词 + -ing  → 表主动/进行（可作主语、宾语、表语、定语、状语）
动词 + -ed   → 表被动/完成（同上）
to + 动词    → 表目的/将来（同上）
```

**核心逻辑**：谓语只能是动词；动词只能作谓语。所以不作谓语的动词，必须变成非谓语。
一句话有多个动词时，主要动作（跟在主语后面的）作谓语，其余变非谓语。

### 系动词六类（完整分类）
| 类型 | 词汇 | 备注 |
|------|------|------|
| 表状态 | be动词 | 连接主语和表语，无实义 |
| 表感官 | look, sound, taste, smell, feel | 后面只能接形容词 |
| 表变化 | get, become, turn, grow, fall | 这些词也可作实义动词 |
| 表保持 | keep, stay, remain, stand | |
| 表似乎 | seem, appear | |
| 表终止 | prove | |

**"晓艳有话说"警示**：不认识的动词 → 100%是实义动词，因为系动词只有以上几十个；判断主谓宾 vs 主谓表，先看谓语动词类型。

### 长难句分析三步走（书中标准流程）
1. **找主干**：找到谓语动词（具有时态和语态的动词），往左推主语，往右找宾语/表语
2. **剥修饰**：将定语从句、状语从句、同位语、非谓语动词等括起来（果实）
3. **翻译主干**：先翻主干，再填修饰（先翻葡萄藤，再挂葡萄）

### 中式英语常见错误（书中典型例题）
- "我的英语说得很好" → 错：My English speaks well → 正：I speak English well.
- "北京西站，到了" → 错：Beijing West Railway Station is arriving → 正：We are arriving at Beijing West Railway Station.
- "前面正在修路" → 错：The front is building the road → 正：The road is being built in front.（路不能自己修自己）
