## 一、长难句体系

### 简单句五大句型
1. 主 + 谓
2. 主 + 谓 + 宾
3. 主 + 谓 + 表（系表）
4. 主 + 谓 + 双宾
5. 主 + 谓 + 宾 + 宾补

### 句子成分
| 成分 | 可以由什么充当 |
|------|--------------|
| 主语 | 名词、代词、非谓语动词、从句 |
| 谓语 | 实义动词、系动词 |
| 宾语 | 名词、代词、非谓语动词、从句 |
| 表语 | 名词、代词、形容词、非谓语动词、介词短语、从句 |
| 定语 | 名词、形容词、非谓语动词、从句、介词短语 |
| 状语 | 副词、介词短语、非谓语动词、从句 |
| 同位语 | 名词、代词、非谓语动词、从句 |

### 核心规则
- 表语修饰主语；定语修饰名词
- 介词短语只能作定语、表语、状语（不能作主语/宾语）
- 系动词无被动语态
- 从句和非谓语动词可充当的成分一致

### 长难句公式
```
（状语 / As非限制定语），主语（定语/同位语/状语）+ 谓语 + 宾语（定语/同位语/状语）
```

## 二、阅读理解方法

### 核心规律
- **原句重现 = 必错**：选项原封不动复制原文措辞，100%是干扰项；正确答案必有同义替换
- **按序出题**：四篇文章顺序与题目顺序一致，定位不会跨越
- **长难句是出题点**：每篇必有5-6个长难句，出题老师专在这里设陷阱

### 定位词选取原则
优先选：
1. 首字母大写的人名、地名、机构名
2. 具体时间、年份
3. 阿拉伯数字
4. 专业名词、形容词
（避免选：代词、副词、泛化名词）

### 题型策略
- **态度题**：先排除不可能的态度词（too extreme），再用题干定位段落，看作者论述立场
- **细节题**：严格定位，答案在原文附近，同义替换验证
- **主旨题**：看首段和各段首句，避免过于细节的选项

## 三、写作方法

### 三大写作原则
1. 写不来的词汇 → 换成自己会的词（保证正确）
2. 写不来的长难句 → 写简单句（保证正确）
3. 背一个大作文模板 + 一个小作文模板

### 大作文三段式框架
**第一段（3-4句）：描述图表 + 引出中心**
- "What is obvious is that..."
- 主语从句 + 中心论点

**第二段（4句）：分析原因**
- 总述 + 三点原因（First/Moreover/Last but not least）
- 搭配虚拟语气或让步从句提升档次

**第三段（4句）：总结 + 措施 + 口号**
- 总结问题
- 两点措施
- 升华结尾

### 高分句型
```
被动句：... is supposed to be respected by ...
There be：There remain immense amounts of factors which can account for...
比较：... proves as momentous as ..., which plays a key role in ...
递进：The harder one works, the luckier he will be.
同位语：Teamwork, a Chinese conventional virtue, plays a crucial role...
```

### 高级替换词
| 普通词 | 替换词 |
|--------|--------|
| think | maintain / assert / contend |
| many | a sea of / immense amounts of |
| people | youngsters / the elderly / private individuals |
| good | beneficial / constructive |
| bad | detrimental / adverse |

### 逻辑关系词（只要上下句有逻辑关系，必须用）
- 递进：moreover, furthermore, in addition
- 转折：nevertheless, however, on the contrary
- 因果：consequently, as a result, thereby

### 小作文（书信类）
- 公务书信：称呼 + 自我介绍 + 写作目的 + 正文三点 + 期待回信 + 落款
- 告示Notice：标题 + 正文 + 欢迎语 + 联系方式
