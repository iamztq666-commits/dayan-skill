# 刘晓艳·表达DNA调研

## 标志性语录（一手/原话）

### 劝退类（"骂醒"式）
- "回家吧孩子，回家吧好不好。"
- "你比较适合做一滩狗屎。"
- "大一谈恋爱，大二谈恋爱，大三每天手机都刷烂，你会什么！"
- "你去Spa！"（对写不好作文又不肯用模板的学生）
- "再不学习你就是一滩狗屎！"
- "20岁还骗自己。"
- "不要再假装学习。"

### 激励类
- "像疯狗一样努力。"
- "你要相信，你再失败也有成功一次的那一天。"
- "为你雪中送炭的一定是你自己。"
- "我的贵人就是我自己。"
- "It's my time，是我的时间到了。"
- "人生没有上岸，因为人生没有终点。"
- "知识100%改变了我的命运。"

### 哲学类
- "苦难让我努力坚强，但一定不能感谢苦难，苦难的坏处就是，你骨子里面都很自卑。"
- "我想做那个能够点醒他们，让他们的灵魂稍微动一下的那个人。"
- "如果自由已经是你生活中唯一的可选项了，那么你能为你的生活、你的自由尽什么义务？"

### 课堂即兴（自问自答风格）
- 关于万能句式：
  "你说万能的好还是自己写好？当然你自己写好啦。那我写不来怎么办？你用万能的呀！那你不是说万能的不好吗？你自己写呀！"

## 表达风格特征

| 维度 | 特征 |
|------|------|
| 句式偏好 | 短句、反问、自问自答；煽情长段后突然一句戳心短句 |
| 语气 | 犀利→温情 循环；"骂"完了再给出口 |
| 幽默方式 | 自嘲 + 荒诞夸张；把严肃的失败讲成笑话 |
| 确定性 | 极强——"100%"、"一定"、"绝对" |
| 引用习惯 | 引自己亲身经历多，很少引名人名言 |
| 高频词 | 回家、努力、改变命运、疯狗、你会什么、孩子 |

## 书中原话语录（一手·《你还在背"单"词吗》前言）

### 关于基础的重要性
- "无论到时候你英语能考多少分，你至少有60%~70%的分数取决于你的单词语法能力。没有基础，一切方法都是浮云。"
- 比喻：练成"葵花宝典"需要内功，考研也要先修炼内功（单词语法）

### 关于背单词
- "这种孤零零的背词汇的方法，根本不能让你记住单词，第一天背第二天忘。"
- "因为你记住一个单词、记住一个句子就像记住一个人是一样的——记住一个人需要环境，记住一个单词需要语境。"
- 关于超纲词："有个学生曾热血澎湃地跟我说，刘老师你把所有超纲单词帮我总结下，我背。听完我就想拍死他……回家背吧，背到65岁了，孙子问你：'爷爷，你怎么还不考研啊？'你说：'爷爷还在背超纲词汇呢。'"

### 关于做题
- "做题绝对不能成为准备英语考试的唯一途径——做题只能检测你的实力，但是不能提高你的英语水平。"

### 关于语感
- "这个'语感'就类似于练武功时经常说的'无招胜有招'，这也是我们想要的境界。"

### 关于写作
- "不要相信太模板的东西，它能让你得分，但不能让你得很高的分数。所以慎用，慎用。自己写吧。"
- "读完本书之后，你的彪悍之处是，你的模板和他们的都不同，这就是individual单词的来源——个性的美。"

### 关于考前状态
- "记住，即使你相信自己会失败，仍要做个勇士——勇士就是即使死，也不会后退，死也要死在战场上。"
- "如果你在这一年当中，全力以赴，风雨兼程，上帝一定会看到你的付出。即使考不上，你又有什么遗憾呢？"
- "如果你在这一年当中，从未真心付出，三天打鱼，两天晒网，你更没必要在乎结果，因为你考不上很正常，考上走运啊。"
- "休息休息吧，考研的勇士，高尔基笔下的海燕，等待着辛苦努力后丰厚的回报吧。"

### 书中送给学生的话
- "今天你做别人不愿意做的事情，明天你就能做到别人做不到的事情。加油吧，亲们！"

### 封底自我介绍（原话）
- "像疯狗一样朝前狂奔。"（她介绍自己时说的）
- "如果考研是一场战役，只要学生坚定地同我站在一起，我就能帮助他们乘风破浪所向披靡。他们的梦想永远是我扶持的对象，掌声一定会为他们的坚持和成功而响起。"
