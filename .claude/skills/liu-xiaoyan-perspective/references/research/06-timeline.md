# 刘晓艳·人物时间线

| 时间 | 事件 | 影响 |
|------|------|------|
| 出生 | 河南贫苦农村，母亲早逝，父亲缺位，由姑姑从初二起抚养至高三 | 寒门背景成为她一生叙事的底色和情感资源 |
| ~1999 | 第一次高考失利，极度紧张发挥失常 | 首次体验失败，强化了"屡败屡战"的性格基调 |
| ~2000 | 第二次高考，调剂商丘师范学院英语专业（非本意志愿） | 用自身经历反复告诫学生"专业不代表命运" |
| ~2004 | 考研报考清华法学，笔试365分进入复试，复试被刷，调剂贵州大学 | "上研究生之前，我的人生没有成功过一次"——考研经历成为最核心的励志素材 |
| 2005 | 仅用6个月备考司法考试，贵州省第二名 | 证明自己的学习方法有效，建立教学自信 |
| ~2006后 | 毕业后考公、考编全部失败，首份工作为高校临时辅导员，月薪不足1800元 | 彻底走向教培行业，"知识是我唯一的武器" |
| 2009 | 加入新东方，获评新东方集团优秀教师 | 考研英语名师生涯起点 |
| 2011-2012 | 新东方集团国内部特邀培训师 | 全国巡讲，建立考研圈影响力 |
| 2009-2013 | 新东方集团考研英语巡讲师 | 覆盖全国高校，粉丝量级爆发 |
| ~2016-2017 | 出版《你还在背"单"词吗》《不就是语法和长难句吗》等系列书籍 | 知识体系系统化，"刘晓艳考研英语"成为品牌 |
| ~2018前后 | 从新东方转至启航考研 | 职业路径调整 |
| 2021年8月 | **刘翔事件**：课堂讽刺刘翔伤退"十几亿人看着你，你扭头就走"；同期流出**董存瑞事件**：讲述虚假段子称"不要相信河南人"。8月2日道歉，微博被永久封禁（当时约470万粉丝） | 职业生涯最大危机，被迫退出考研英语领域 |
| 2021年后 | 退出考研英语，转战四六级、专升本领域 | "姐已经不在考研圈了，但考研圈依然有姐的传说" |
| 2024年12月 | 四六级考试前，讲课视频再次在抖音/B站爆红，表情包刷屏，"回家吧孩子"成全网梗 | 以新身份二次出圈，受众从考研生扩展至全体大学生 |
| 2025年5月 | **周思成争议**：同行质疑其英语水平"倒数第一"、学历造假（宣传清华但实为贵州大学）。刘晓艳发文未正面回应 | 学历和专业能力受到公开质疑，争议持续 |
